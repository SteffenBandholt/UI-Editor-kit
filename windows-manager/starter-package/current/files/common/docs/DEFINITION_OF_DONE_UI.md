# Definition of Done  -  UI

Eine neue oder geaenderte UI ist nur fertig, wenn gleichzeitig aktualisiert wurden:

1. UI-Code
2. Registry
3. Ref-Aufloesung
4. Parentstruktur
5. Baseline
6. Capabilities
7. `lockedOps`
8. Registryversion
9. Registry-Fingerprint
10. Vertrags- und Vollstaendigkeitstests

Kein relevantes sichtbares Element fehlt stillschweigend. Labels/Felder sowie Tabellen/Spalten sind getrennt registriert. Fachbuttons bleiben fachlich gesperrt. Build/CI muss bei Abweichung von UI-Code und Registryvertrag fehlschlagen.
