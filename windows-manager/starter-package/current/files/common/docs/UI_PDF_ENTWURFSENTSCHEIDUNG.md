# UI-/PDF-Entwurfsentscheidung

Vor der Umsetzung ausfuellen:

- Art: UI / PDF / beides / nicht editorrelevant
- Editorfaehig: ja / nein, mit Begruendung
- Elemente: ID, Name, Typ, Rolle, Parent, Reihenfolge, Sichtbarkeit, editierbar, `allowedOps`, `lockedOps`
- Tabellen: sichtbare Spalten in echter Reihenfolge und `columnRole`
- Felder/Labels: getrennte Elemente unter einer gemeinsamen Feldgruppe
- Fachaktionen: als Layoutobjekt oder vollstaendig gesperrt; Ausfuehrung immer gesperrt
- Pruefung: Vertrags- und Vollstaendigkeitscheck nennen

Ohne vollstaendige Entscheidung: STOPP.
