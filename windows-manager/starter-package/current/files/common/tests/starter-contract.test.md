# Testskelett

Der Ziel-App-Test muss mindestens Manifest, Registry-Inventar, eindeutige IDs, Parents, Refs, Baselines, Capabilities, Fachaktionssperren, Registryversion/Fingerprint, Refresh und Rollback pruefen. Ein neuer Scope beginnt blockiert und wird erst nach vollstaendiger Ziel-App-Registrierung freigegeben.
