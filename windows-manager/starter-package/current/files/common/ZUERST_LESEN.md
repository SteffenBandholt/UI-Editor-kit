# App-Starterpaket  -  zuerst lesen

Vor Beginn jeder UI-Entwicklung muss das App-Starterpaket installiert sein.
Soll eine bestehende App bearbeitet werden, ist zuerst im nativen Manager **Bestehende App nachruesten** auszufuehren.

Der Editor erkennt keine UI. Die Ziel-App besitzt Registry, stabile IDs, Parentstruktur, Referenzen, Baselines, Capabilities, `lockedOps`, Registryversion und Fingerprint.

Vor jeder UI-/PDF-Aenderung sind `AGENTS.md`, `Arbeitsanweisung.md`, `docs/UI_PDF_ENTWURFSENTSCHEIDUNG.md`, `docs/REGISTRY_REGELN.md` und `docs/DEFINITION_OF_DONE_UI.md` zu lesen.
