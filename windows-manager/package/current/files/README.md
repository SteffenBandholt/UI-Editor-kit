# Verwaltete UI-Editor-Integration

Dieser Ordner wird ausschließlich durch den nativen M78-Manager verwaltet. Die Ziel-App stellt Registry, HostAdapter, Editorprojekte und Startkonfiguration über `ui-editor-target.json` ausdrücklich bereit. Layoutprofile und Fachdaten liegen nicht in diesem Ordner und werden bei einer Deinstallation nicht gelöscht.
